# Scripts

- `serving/`: Wan serving entry points, cache policies, and TeaCache integration.
- `experiments/`: latent profiling and A/B cache-survival experiments.
- `analysis/`: scripts that summarize and plot A/B experiment results.
- `run_serving.sh`: cache-policy and workload sweep.
- `run_vbench200_similar_compare.sh`: Nirvana + TeaCache comparison run.
- `setup.sh`: optional environment-specific Hugging Face configuration.

Run these scripts from the project root using their repository-relative paths.
